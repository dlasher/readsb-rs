# Feature Wiring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert every unconnected Rust feature stub into a wired production path. No deletions — every original readsb C feature has a Rust equivalent that will eventually be connected.

**Architecture:** Six independent phases, each deployable. Earlier phases deliver user-visible fixes (gain control, network output); later phases complete parity with the C reference (JSON output, Mode A/C, stats).

**Key insight from cross-reference:** The "dead code" audit found that almost every flagged item has a live counterpart in `readsb-rtltcp` (the C reference). These are **incomplete ports**, not accidental dead code. The fix is to wire them up, not delete them.

**Tech Stack:** Rust (tokio+clap), serde + serde_json, tokio broadcast channels

> **TDD Requirement:** Every new production function requires a RED (write failing test) → GREEN (minimal implementation) → REFACTOR cycle. Steps marked `[RED]` must be completed and verified before the corresponding `[GREEN]` step. No production code without a failing test first. Steps marked `[no test needed]` involve only annotations, deletions, or trivial one-line delegates — no behavioral change, no test required.

    mut stream: TcpStream,

    let (mut rx, mut tx) = stream.split();

    parser: InputParser,

  /// Extract ACARS-style callsign from Comm-B aircraft ident MB field.
  pub fn commb_callsign(mb: &[u8]) -> String {
      // 6-bit packed in 42 bits (MB[1..6], 7 bytes = 48 bits, 42 used)
      let mut chars = String::with_capacity(8);
      let bits: u64 = mb.iter().take(7).fold(0u64, |acc, &b| (acc << 8) | b as u64);
      // Shift out the first 6 bits (BDS register) then decode remaining 42 bits
      for i in (0..42).step_by(6).rev() {
          let ch = ((bits >> i) & 0x3F) as u8;
          let c = ais_6bit_to_ascii(ch);
          if c == '@' { break; }
          chars.push(c);
      }
      chars.trim().to_string()
  }
